# 🔥 MALA POS & Cost Management Suite (หม่าล่าทอด)

ระบบคีย์ออเดอร์และบันทึกต้นทุนร้านหม่าล่าทอด (สำหรับเจ้าของร้านคีย์รับออเดอร์จาก LINE OA) เชื่อมต่อกับ Google Sheets Apps Script แบบ Real-time

---

## 📁 โครงสร้างไฟล์ในโฟลเดอร์นี้

| ไฟล์ | รายละเอียด |
|---|---|
| 🛒 `index.html` | **หน้าคีย์ออเดอร์หลัก** — เลือกเมนู, สรุปจำนวนไม้และยอดโอน, บันทึกออเดอร์ใน 1 คลิก, สถิติยอดขาย |
| 📱 `index-ipad-premium.html` | สำเนาหน้าคีย์ออเดอร์สำหรับเปิดบน iPad / Safari / Chrome |
| 🧾 `วัตถุดิบ.html` | **ระบบบันทึกค่าวัตถุดิบและต้นทุน** — บันทึกรายจ่ายแต่ละรอบ, แนบสลิปใบเสร็จ, สรุปต้นทุน |
| 📦 `ingredients.html` | สำเนาภาษาอังกฤษของระบบบันทึกค่าวัตถุดิบ |
| 📖 `คู่มือการใช้งาน.md` | เอกสารแนะนำการใช้งาน |

---

## 🌟 จุดเด่นและขั้นตอนการคีย์ออเดอร์

### 1. 🛒 ระบบคีย์ออเดอร์หน้าร้าน (MALA POS)
- **Fast 1-Click Save**: แตะเลือกเมนูจากแชท LINE OA > ใส่ชื่อลูกค้า/หมายเหตุ > กดปุ่ม **"💾 บันทึกออเดอร์"** ครั้งเดียว บันทึกลง Google Sheets ทันที
- **Quick Note Tags**: มีปุ่มแท็กด่วนให้กดเพิ่มหมายเหตุได้เร็ว (`เผ็ดน้อย`, `เผ็ดกลาง`, `เผ็ดมาก`, `ไม่เผ็ด`, `โอนแล้ว`)
- **Category Filter & Search**: กรองเมนูตามหมวด (เนื้อสัตว์, ลูกชิ้น/เต้าหู้, ผัก/เห็ด) หรือค้นหาด่วน (กด `/`)
- **Quick Custom Item**: ปุ่ม `+ เมนูพิเศษ / กำหนดราคาเอง` สำหรับใส่ยอดพิเศษหรือค่าน้ำ/ค่าส่ง
- **Dashboard & Profit Analytics**: สรุปยอดขายวันนี้, กราฟ 7 วัน, อันดับเมนูขายดี, และ **คำนวณกำไรสุทธิ (ยอดขาย - ต้นทุนวัตถุดิบ)**

### 2. 🧾 ระบบบันทึกค่าวัตถุดิบ (MALA COST)
- **Smart Round Selection**: เลือกรอบการซื้อเดิม หรือกดสร้างรอบด่วน (`รอบวันนี้`, `สัปดาห์นี้`)
- **Quick Ingredient Chips**: แตะเลือกชื่อวัตถุดิบยอดนิยมได้ทันที (หมูสามชั้น, ไส้กรอกแดง, พริกหม่าล่า ฯลฯ)
- **Advanced Slip Upload**:
  - รองรับการลากไฟล์มาวาง (Drag & Drop)
  - รองรับการ **วางรูปสลิปจากคลิปบอร์ด (Ctrl+V / Cmd+V)**
  - **บีบอัดรูปภาพอัตโนมัติก่อนส่ง** ป้องกันปัญหาเน็ตช้าหรือไฟล์ใหญ่เกินไป
- **Cost Summary & Share**: ดูยอดรายจ่ายรวม, จำนวนรอบ, และปุ่ม **"📋 คัดลอกสรุปส่ง LINE"**

## 🚀 วิธีเปิดใช้งาน

1. ดับเบิลคลิกเปิดไฟล์ `index.html` บนเบราว์เซอร์
2. กดปุ่ม **"⚙️ ตั้งค่า"** เพื่อกรอก Web App URL ของ Google Sheets
3. บน iPad: กด **Share > "Add to Home Screen" (เพิ่มไปยังหน้าจอโฮม)** เพื่อเปิดใช้งานแบบเต็มจอ
